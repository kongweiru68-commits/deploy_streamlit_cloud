# 温室甜菜水分胁迫智能监测与预警平台（云端部署精简包）

## 部署到 Streamlit Community Cloud 步骤（0 元）
1. 在 GitHub 新建一个仓库（Public），把本文件夹内所有文件上传（或 `git push`）到该仓库根目录。
2. 打开 https://share.streamlit.io 使用 GitHub 登录，点击 **New app**。
3. 选择刚创建的仓库，**Main file path** 填写：`code/app.py`，点击 **Deploy!**。
4. 等待 1~2 分钟构建完成后，即可获得永久公开网址（`https://xxx.streamlit.app`）。

默认登录账号：管理员 `admin` / `123456`，普通巡检员 `inspector` / `123456`。
